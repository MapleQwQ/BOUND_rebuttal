# Results

This directory stores retained BOUND outputs and result-recomputation utilities.
Generated outputs from new runs are also written under this directory.

## Repository Structure

```text
results/
├── paper/
│   ├── package_recommendation/          # Retained edit-prompt and unseen-prompt BOUND evaluations
│   ├── cross_task_generalization/       # Retained cross-task BOUND evaluations
│   └── paper_raw_data.md                # Human-readable index of retained BOUND rows
├── compute_result.py                    # Recompute summary tables from results/paper/
├── recomputed_bound_tables.md           # Output generated by compute_result.py
└── method_runs/
    ├── package_recommendation/          # Generated by run-package-recommendation
    └── cross_task/                      # Generated by run-cross-task
```

Retained cross-task outputs are stored under:

```text
results/paper/cross_task_generalization/{model}/BOUND/fold_{A|B|C|D}/bound/
```

Each retained cross-task directory contains:

```text
cross_task_case_grouped.jsonl
cross_task_summary.json
cross_task_summary.md
```

## Recomputing Retained Results

Run the following command from the package root:

```bash
python results/compute_result.py
```

The script reads only files under `results/paper/` and writes:

```text
results/recomputed_bound_tables.md
```
