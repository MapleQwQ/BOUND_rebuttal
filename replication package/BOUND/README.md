# BOUND: Boundary-Oriented Model Editing for Package Hallucination

This repository provides the replication package for our ICSE submission titled **"BOUND: Boundary-Oriented Model Editing for Package Hallucination"**.

BOUND is a model-editing approach for mitigating package hallucinations in large language models.
Given package-recommendation prompts that contain valid packages and hallucinated packages, BOUND first localizes modules that are sensitive to the package-validity boundary and then applies boundary-aware LoRA editing to suppress hallucinated packages while preserving useful package knowledge.

## Environment Setup

Use Python 3.10+ with a CUDA-compatible PyTorch installation.
We recommend creating a clean Conda environment:

```bash
conda create -n bound python=3.10
conda activate bound
pip install -r requirements.txt
```

## Model Setup

Download and place the required model weights under `models/`:

```text
models/deepseekcoder
models/qwen3-8B
models/llama3.1
```

Alternatively, edit `model_path` in the corresponding YAML file:

```text
bound/hparams/deepseekcoder.yaml
bound/hparams/qwen3.yaml
bound/hparams/llama3.1.yaml
```

GPU selection is configured in the YAML files:

```yaml
gpu: 0
```

## Running an Experiment

Run the full BOUND package-recommendation workflow for one model and one fold:

```bash
python main.py run-package-recommendation --model deepseekcoder --fold A
```

This command selects the requested edit fold, localizes package-validity boundary modules, applies boundary-aware LoRA editing, and evaluates the edited model on edit and unseen prompts.


After an edited delta has been produced, run the cross-task generalization experiment:

```bash
python main.py run-cross-task --model deepseekcoder --fold A
```

The cross-task command reads the 100 base cross-task prompts in `data/package_hallucination/{model}/cross_task_test100.jsonl`.
Each prompt is evaluated with five generated responses internally, so the progress bar counts base prompts rather than expanded prompt-repeat pairs.

To recompute the retained BOUND summary tables without rerunning GPU experiments:

```bash
python results/compute_result.py
```

## Output Format

A full package-recommendation run writes a self-contained experiment directory:

```text
results/method_runs/package_recommendation/{model}/fold_{A|B|C|D}/bound/
```

The main files in this directory are:

```text
experiment_config.json                 # Resolved configuration and selected edit cases
selected_task_recommend_cases.jsonl    # Edit cases used by the run
localization_report.json               # Ranked localized modules
bound_delta.pt                         # Learned BOUND LoRA delta
bound_config.json                      # Editing configuration and resolved target modules
train_log.jsonl                        # Training loss logs
eval_edit_prompts.json                 # Edit-prompt evaluation
eval_unseen_prompts.json               # Unseen-prompt evaluation
run_status.json                        # Latest run stage and status
```

Cross-task runs write:

```text
results/method_runs/cross_task/{model}/fold_{A|B|C|D}/bound/
```

with the following files:

```text
cross_task_case_grouped.jsonl          # One row per base prompt, with five generated repeats grouped together
cross_task_summary.json                # Aggregate cross-task metrics
case.json                              # Run metadata
```

The retained paper outputs are stored separately under:

```text
results/paper/package_recommendation/
results/paper/cross_task_generalization/
```

Running `python results/compute_result.py` reads only `results/paper/` and writes:

```text
results/recomputed_bound_tables.md
```
